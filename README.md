## 🛠️ Technology Stack

- **Framework:** Next.js 14 (App Router, Server Components & Client Components)
- **UI & Styling:** React 18/19, TypeScript, Tailwind CSS, Lucide React
- **Motion & Interactive Polish:** Framer Motion, HTML5 Canvas Particle Grid, CSS Hardware Acceleration
- **Data Validation:** Zod Schema Validation
- **Persistence:** Local JSON / SQLite Database with persistent file storage and in-memory fallback
- **SEO & Social:** Dynamic XML Sitemap (`/sitemap.xml`), Robots (`/robots.txt`), JSON-LD Organization Schema, OpenGraph / Twitter Cards
- **Compliance & Accessibility:** Canadian PIPEDA & GDPR compliant privacy notice, WCAG 2.1 AA accessible contrast and semantics

## 🚀 Quick Start & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Configuration
Copy `.env.example` to `.env.local` to customize registered Canadian addresses or contact emails:
```bash
copy .env.example .env.local
```

### 3. Start Development Server
```bash
npm run dev
```
Open **http://localhost:3000** in your browser.

### 4. Build for Production
```bash
npm run build
npm start
```
